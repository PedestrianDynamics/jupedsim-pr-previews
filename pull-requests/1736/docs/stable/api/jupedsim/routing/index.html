    Coupled pedestrian + cyclist/e-scooter shared-space solver (STEP-UP DC1 & DC10).

    Enforces a dynamic 8.0 km/h (2.222 m/s) micro-mobility speed cap whenever local pedestrian crowd density exceeds 0.35 ped/m^2 and selects predictive tau_CPA / d_CPA collision-avoidance steering & braking.

    Compute velocity- and gaze-anisotropic pedestrian accelerations with density-adaptive dyadic V-formation / single-file transitions (DC1).

    Above dyad_single_file_density_m2 (1.2 ped/m^2), walking dyads reconfigure from abreast V-formation (lateral spacing 0.75 m, slight 0.12 m forward conversational V-cupping) into leader-follower single-file alignment (longitudinal spacing 0.85 m, zero lateral offset).

    fov_attenuation(gaze_dir: numpy.typing.ArrayLike, rel_pos: numpy.typing.ArrayLike, lambda_aniso: float = 0.35, phone_distracted: bool = False) → float[source]#

    Compute anisotropic visual field-of-view weight w(phi) in [lambda_aniso, 1].

    Follows Johansson, Helbing & Shukla (2007) with optional smartphone gaze aversion attenuation reducing forward visual anticipation.
